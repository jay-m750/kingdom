# Feature Specification: 高中物理電路分析工具（機械系申請應用）

**Feature Branch**: `001-physics-circuit-analysis`
**Created**: 2026-03-13
**Status**: Draft
**Input**: User description: "幫我做一個高中物理電路的分析，我要申請機械系相關的應用"
**Language Requirement**: 本文件內容 MUST 使用繁體中文撰寫。
**Design Constraint**: 僅記錄需求驅動的最小必要範圍，避免過度設計。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 基礎電路分析計算 (Priority: P1)

高中生輸入電路元件參數（電阻值、電壓源、電流源），系統自動計算各支路電流、節點電壓及功率，並以結構化方式呈現結果。學生可利用此功能驗證手算答案，加深對歐姆定律與克希荷夫定律的理解。

**Why this priority**: 這是整個功能的核心能力，無此功能其他故事皆無法實現。學生最基本的需求是確認電路計算是否正確。

**Independent Test**: 給定一個串並聯混合電路（如 3 個電阻），輸入參數後系統輸出各元件電流與電壓，學生可與教科書答案比對。

**Acceptance Scenarios**:

1. **Given** 使用者輸入一組串聯電路（電壓 12V、電阻 R1=4Ω、R2=8Ω），**When** 使用者要求分析，**Then** 系統顯示總電流 1A、R1 電壓 4V、R2 電壓 8V 及各元件消耗功率。
2. **Given** 使用者輸入一組並聯電路（電壓 6V、R1=6Ω、R2=3Ω），**When** 使用者要求分析，**Then** 系統顯示總電流 3A、各支路電流（R1=1A、R2=2A）及總功率 18W。
3. **Given** 使用者輸入無效參數（如電阻值為 0 或負數），**When** 使用者要求分析，**Then** 系統顯示明確的錯誤提示，說明無效原因，不進行計算。

---

### User Story 2 - 機械工程應用場景模擬 (Priority: P2)

高中生選擇機械工程相關應用場景（如直流電動機起動電路、電磁鐵致動器、溫度感測器回路），系統將電路分析結果對應到機械工程概念（如轉矩、磁力、量測訊號），幫助學生理解電路在機械系統中的實際角色。

**Why this priority**: 此功能直接回應「申請機械系」的需求，使電路知識與機械系大學課程產生連結，提升申請備審資料的深度。

**Independent Test**: 選擇「直流電動機起動電路」場景，輸入電源電壓與電樞電阻後，系統輸出起動電流及換算的理論起動轉矩，學生可截圖附於備審資料中。

**Acceptance Scenarios**:

1. **Given** 使用者選擇「直流電動機」應用場景並輸入電壓 24V、電樞電阻 2Ω、反電動勢常數，**When** 要求分析，**Then** 系統顯示起動電流、穩態電流及對應的轉矩說明。
2. **Given** 使用者選擇「電磁鐵致動器」場景並輸入線圈參數，**When** 要求分析，**Then** 系統顯示線圈電流及定性說明其產生的磁力強度。
3. **Given** 使用者選擇「溫度感測器（熱敏電阻）分壓電路」場景，**When** 要求分析，**Then** 系統顯示不同溫度下的輸出電壓變化，說明如何用於溫度量測。

---

### User Story 3 - 分析結果匯出與備審呈現 (Priority: P3)

高中生完成電路分析後，可將分析過程、電路圖示及計算結果以整潔格式匯出，用於製作申請機械系的備審資料（學習歷程檔案或自述）。

**Why this priority**: 學生的最終目標是申請機械系，需要能將學習成果轉化為可呈現的文件。此功能雖非核心計算，但對申請目標至關重要。

**Independent Test**: 完成一次電路分析後，選擇匯出功能，系統產生包含電路說明、計算步驟與結果的文件，學生可直接附於備審資料。

**Acceptance Scenarios**:

1. **Given** 使用者完成一次電路分析，**When** 選擇匯出，**Then** 系統產生包含電路描述、輸入參數、逐步計算過程及最終結果的文件。
2. **Given** 使用者完成機械工程應用場景分析，**When** 選擇匯出，**Then** 文件中包含該應用場景的說明及電路與機械概念的對應關係。

---

### Edge Cases

- 當電路存在短路（電阻為 0 的迴路）時，系統應偵測並告知使用者，而非產生無限大電流計算結果。
- 當電路圖不連通（孤立節點）時，系統應提示電路結構有誤，請使用者確認連接關係。
- 當使用者輸入的應用場景參數超出高中物理教學範疇（如需用到微積分的暫態分析）時，系統應說明此功能僅涵蓋穩態直流電路。
- 當使用者未輸入任何電路元件即要求分析時，系統應提示至少需輸入一個電源與一個負載。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系統必須支援串聯、並聯及串並聯混合電路的穩態直流分析，計算各支路電流、各節點電壓與各元件消耗功率。
- **FR-002**: 系統必須套用歐姆定律（V = IR）及克希荷夫電流定律（KCL）與電壓定律（KVL）進行計算，計算結果精確至小數點後兩位。
- **FR-003**: 使用者必須能夠輸入電路元件（電壓源、電阻），系統需提供清楚的輸入欄位說明元件意義與單位（V、Ω、A、W）。
- **FR-004**: 系統必須提供至少三種機械工程應用場景（直流電動機、電磁鐵致動器、熱敏電阻感測回路），每個場景有預設電路結構與對應的機械工程概念說明。
- **FR-005**: 系統必須在使用者輸入不合法參數（負數電阻、零電阻短路、空白欄位）時顯示明確的錯誤訊息，阻止計算並指引使用者修正。
- **FR-006**: 使用者必須能夠匯出分析結果，匯出內容包含電路描述、輸入參數表、計算步驟說明及最終數值結果。
- **FR-007**: 系統必須以繁體中文呈現所有使用者介面文字、說明與錯誤訊息。

### Key Entities

- **電路（Circuit）**：使用者建立的電路，包含拓撲結構（串聯/並聯）、元件清單及分析結果；一次工作階段可包含一個電路。
- **電路元件（Component）**：組成電路的基本單元，分為電壓源（屬性：電壓值）與電阻（屬性：電阻值、位置標號）。
- **分析結果（AnalysisResult）**：由電路計算得出，包含每個元件的電壓、電流及功率數值，以及整體電路總功率。
- **應用場景（ApplicationScenario）**：預定義的機械工程應用情境，包含場景名稱、電路預設結構、機械工程概念說明及對應計算結果的詮釋說明。
- **匯出文件（ExportDocument）**：使用者選擇匯出時產生的整合文件，包含電路描述、計算過程與機械應用說明。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用者可在 3 分鐘內完成一組串並聯電路的輸入、分析與結果查看，不需參閱說明文件。
- **SC-002**: 電路計算結果與手算正確答案的誤差在 ±1%（小數點後兩位精確度）以內，涵蓋串聯、並聯及混合電路。
- **SC-003**: 90% 以上的測試使用者能夠在首次使用時正確完成至少一個機械工程應用場景的分析，無需外部協助。
- **SC-004**: 所有必填欄位皆有明確說明，使用者輸入錯誤時 100% 收到可理解的繁體中文提示，且不會因輸入錯誤造成系統異常。
- **SC-005**: 匯出功能產生的文件，可直接附入學習歷程檔案而不需手動格式調整，達到 80% 以上使用者認為文件格式適合備審資料。

## Assumptions

- 本功能聚焦於**穩態直流電路（DC steady-state）**，不涵蓋交流電路（AC）、暫態響應（RC/RL transient）或三相電路，符合高中物理教學範疇。
- 機械工程應用場景採用**定性說明為主、定量計算為輔**的方式，不要求完整的電機學計算公式（如磁通量方程式），以高中生可理解的層次呈現。
- 假設使用者為**高中生或應屆畢業生**，具備高中物理基礎知識，但不具備大學工程數學能力。
- 電路規模限定為**小型電路（最多 10 個元件）**，符合高中教學情境，不處理大型網路電路。
- 匯出格式預設為通用文件格式（如 PDF 或純文字），適合附入學習歷程檔案，不針對特定學校申請系統設計。
